## Featured Projects

<details>
<summary><b>Smart Loan Recovery System</b></summary>
<br/>

A Machine Learning project that predicts loan recovery outcomes — **Fully Recovered**, **Partially Recovered**, or **Written Off** — based on borrower profiles, loan details, and repayment behavior.

| Attribute | Details |
|---|---|
| **Stack** | Python, Pandas, NumPy, Scikit-Learn, XGBoost, Streamlit |
| **Dataset** | 500 loan records covering borrower info, loan info, repayment behavior & collection activity |
| **Feature Engineering** | EMI_Income_Ratio, Outstanding_Loan_Ratio, Collateral_Coverage, Missed_Payment_Rate |
| **Models Compared** | Logistic Regression, Decision Tree, Random Forest, XGBoost |
| **Best Model** | Tuned Random Forest |
| **Performance** | Accuracy: 78% · ROC-AUC: 0.788 |
| **Repository** | [View Repository](https://github.com/srishti200426/Smart-Loan-Recovery-System) |

Engineered domain-specific ratio features to better capture repayment risk, compared four classification models, and tuned the best-performing Random Forest model. Wrapped the final model in a Streamlit app with a real-time prediction interface, confidence scores, and a risk indicator dashboard.

</details>
